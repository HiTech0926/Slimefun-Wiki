# 辐射

辐射是 Slimefun 中放射性物品带来的效果。

当你的物品栏中含有放射性物品时，你会逐渐积累**辐射暴露值**。暴露值范围为 **0 ~ 100**，暴露值越高，你所受到的负面效果就越多、越严重。当暴露值达到 **100** 时，你将受到致命的瞬间伤害。

辐射暴露值会在物品栏上方的动作栏中显示。当暴露值大于 0 时，你会看到当前的辐射计量。

## 辐射等级

放射性物品拥有不同的辐射等级。等级越高，每次检测时增加的暴露值就越多。

| 等级 | 颜色   | 暴露值增量 | 说明                                           |
| ---- | ------ | :--------: | ---------------------------------------------- |
| 低   | 黄色   |     1      | 低辐射等级。会造成伤害，但需要一段时间才会致命 |
| 中   | 黄色   |     2      | 中等辐射等级。可视为默认值                     |
| 高   | 金色   |     3      | 高辐射等级。如果不尽快处理会导致死亡           |
| 极高 | 红色   |     5      | 极高辐射等级。具有致命性，玩家不应轻视         |
| 致死 | 深红色 |     10     | 最高致死等级。玩家基本来不及保护自己，必死无疑 |

如果同时持有多个放射性物品，暴露值会叠加。例如，同时持有 1 个**高**等级和 1 个**中**等级物品，每次检测会增加 3 + 2 = 5 点暴露值。

当你不再持有放射性物品，或受到保护时，暴露值会每秒减少 1 点，直到归零。

## 辐射症状

随着暴露值的增加，你会逐步受到以下负面效果影响：

| 暴露值 | 症状     | 药水效果 | 等级  |
| :----: | -------- | -------- | :---: |
|  ≥ 10  | 缓慢     | 缓慢     |  III  |
|  ≥ 25  | 轻度凋零 | 凋零     |   I   |
|  ≥ 50  | 失明     | 失明     |  IV   |
|  ≥ 75  | 重度凋零 | 凋零     |  IV   |
|  100   | 死亡     | 瞬间伤害 | 49 级 |

## 防护与治疗

### 防化服套装

穿着完整的[防化服套装](/Armor#hazmat-suit)可以让你完全免疫辐射效果。在持有放射性物品时，防化服会阻止暴露值的增加，并使你已有的暴露值逐渐下降。

### 医疗用品

[维他命与药物](/Medical-Supplies)可以立即重置你的辐射暴露值至 0。

### 宽限期

当你死亡后重生或加入服务器时，会获得一段短暂的宽限期。在宽限期内，你不会受到辐射效果的影响。这可以防止在开启死亡不掉落的情况下，因物品栏中仍有放射性物品而立即再次死亡。
